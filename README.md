
# Game//Guess

**Game//Guess** is a web-based daily video game guessing challenge built with Next.js, React and TypeScript.

Players can test their gaming knowledge by identifying video games through daily challenges.

**🎮 [Play Game//Guess](https://www.playgameguess.com/)**

## Overview

Game//Guess is a personal full-stack web development project focused on creating an engaging gaming experience with a modern, responsive interface.

The application uses external video game data from the IGDB API to power its challenges.

## Features

- Daily video game guessing challenges
- Video game data integration through the IGDB API
- Responsive interface for desktop and mobile

## Built With

- Next.js
- React
- TypeScript
- IGDB API

## Technical Challenges

### Game Data Integration

One of the challenges during development was working with game data from the IGDB API.

Individual games can have multiple entries, including demos, showcases and full releases. Handling these variations is important for providing accurate game information and a consistent guessing experience.
